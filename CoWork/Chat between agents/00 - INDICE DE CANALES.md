## CÓMO LEER UN CANAL

Cada mensaje trae este encabezado:

```
### [MSG-###] DE: X → PARA: Y · fecha · Prioridad: NIVEL
**Asunto:** ...
...cuerpo...
**Pide:** acción concreta
**Deadline:** fecha
**Tareas generadas:** LVL-###
```

- `BLOQUEANTE` = algo está detenido, se responde antes que nada.
- `ALTA` = esta semana. `MEDIA` = este sprint. `FYI` = no requiere acción.
- Un mensaje sin **Pide** es FYI por definición.
