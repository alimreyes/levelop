## 🔧 FUNCIONES CLAVE

### Update Timer (cada 1 segundo)

```javascript
useEffect(() => {
  const updateOfferTimers = () => {
    const offerItems = shopItems.filter(item => item.isOffer);
    const newTimers = {};
    
    offerItems.forEach(item => {
      // Calcular tiempo restante
      const expiryTime = new Date(Date.now() + item.durationHours * 60 * 60 * 1000);
      const now = new Date();
      const diff = expiryTime - now;
      
      if (diff <= 0) {
        // Oferta expirada
        newTimers[item.id] = { 
          expired: true, 
          text: 'Expirada', 
          isPulse: false 
        };
      } else {
        const hours = Math.floor(diff / (1000 * 60 * 60));
        const minutes = Math.floor((diff % (1000 * 60 * 60)) / (1000 * 60));
        const seconds = Math.floor((diff % (1000 * 60)) / 1000);
        
        // Determinar si debe pulsar (<1h)
        const isPulse = hours === 0;
        
        if (hours > 0) {
          newTimers[item.id] = {
            expired: false,
            text: `${hours}h ${minutes}m`,
            isPulse: false,
            color: 'text-orange-600'
          };
        } else if (minutes > 0) {
          newTimers[item.id] = {
            expired: false,
            text: `${minutes}m ${seconds}s`,
            isPulse: isPulse,
            color: 'text-red-600'
          };
        } else {
          newTimers[item.id] = {
            expired: false,
            text: `${seconds}s`,
            isPulse: true,
            color: 'text-red-600'
          };
        }
      }
    });
    
    setOfferTimers(newTimers);
  };
  
  updateOfferTimers();
  const interval = setInterval(updateOfferTimers, 1000);
  return () => clearInterval(interval);
}, [shopItems]);
```

### Toggle Filtro (Single-Select)

```javascript
const toggleShopFilter = (filterType, value) => {
  setTempShopFilters(prev => {
    const newFilters = { ...prev };
    
    // Si ya está seleccionado, deseleccionar
    if (newFilters[filterType] === value) {
      newFilters[filterType] = null;
    } else {
      // Si no, seleccionar (reemplaza el anterior)
      newFilters[filterType] = value;
    }
    
    return newFilters;
  });
};
```

**Comportamiento:**
- 1er click: Selecciona el filtro
- 2do click: Deselecciona el filtro
- Click en otro: Cambia la selección

```jsx
{item.isOffer && (
  <div className="absolute top-12 right-2 z-10 flex flex-col gap-1 items-end">
    {/* Badge principal con animación */}
    <div className={`bg-gradient-to-r from-red-600 to-red-500 text-white 
                     text-xs font-bold px-3 py-1.5 rounded-full shadow-lg 
                     ${offerTimers[item.id]?.isPulse ? 'animate-pulse-offer glow-red' : ''}`}>
      <div className="flex items-center gap-1">
        <span className="text-base">🔥</span>
        <span>-{item.discountPercentage}% OFF</span>
      </div>
    </div>
    
    {/* Timer countdown */}
    {offerTimers[item.id] && !offerTimers[item.id].expired && (
      <div className={`bg-black/80 text-white text-[10px] font-bold 
                       px-2 py-1 rounded-full shadow-md backdrop-blur 
                       ${offerTimers[item.id].isPulse ? 'animate-pulse-offer' : ''}`}>
        <div className="flex items-center gap-1">
          <Clock className="w-3 h-3" />
          <span>{offerTimers[item.id].text}</span>
        </div>
      </div>
    )}
    
    {/* Badge expirada */}
    {offerTimers[item.id]?.expired && (
      <div className="bg-gray-600 text-white text-[10px] font-bold 
                      px-2 py-1 rounded-full shadow-md">
        ⏰ Expirada
      </div>
    )}
  </div>
)}
```
